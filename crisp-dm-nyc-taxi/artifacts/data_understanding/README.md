# Data-understanding evidence

Generated by `analysis/data_understanding.py` from `data/NYC_sample_200k.csv`.

- `quality_summary.csv`: row, missingness, duplicate, range, and outlier counts.
- `descriptive_statistics.csv`: descriptive statistics for the working table.
- `hourly_summary.csv`: trip volume and duration by pickup hour.
- `weekday_counts.csv`: trip counts by weekday.
- `fig_01_duration_distribution.png`: raw and log-scale target distributions.
- `fig_02_hourly_patterns.png`: trip volume and median duration by hour.
- `fig_03_spatial_density.png`: pickup and drop-off coordinate samples.

The spatial plots use a broad display window only for visualization; out-of-window rows remain counted in the audit.
