# Data-preparation evidence

Generated by `analysis/data_preparation.py` from the raw NYC sample.

- `exclusion_audit.csv`: one row per input record with the applied decision and quality flags.
- `preparation_summary.csv`: retained/excluded counts and leakage-overlap result.
- `predictor_allowlist.csv`: fields permitted as model predictors.
- `prepared_features.csv`: locally generated feature table for the next modeling step.

The prepared feature table is intentionally local because it is a derived 40 MB artifact. It can always be regenerated from the raw CSV by running the script.
