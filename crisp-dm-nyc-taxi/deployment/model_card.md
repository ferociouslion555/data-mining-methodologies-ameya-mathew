# Model card

Intended use: educational ETA-regression demonstration.

Training data: declared NYC taxi sample described in the notebook.

Primary metric: RMSLE; secondary metrics: MAE and median absolute error.

Limitations: single dataset period, limited covariates, no traffic/weather/event data, no uncertainty interval, and no production monitoring. The service is an educational prototype and should not be used for operational dispatch without additional validation, monitoring, security review, and rollback procedures.
