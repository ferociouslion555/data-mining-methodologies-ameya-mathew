# Discovering Retail Structure with the KDD Process

This KDD project turns 541,909 Online Retail transactions into interpretable knowledge. Selection and preprocessing remove cancellations, unidentified customers, and invalid transactions. Transformation creates customer-level RFM features and a basket matrix. Data mining then finds two RFM customer groups and product co-occurrence rules.

The best silhouette score occurred at k=2. The strongest product associations included Regency teacup variants with lift values above 15. These relationships are useful hypotheses for merchandising analysis, not proof of causal demand. Temporal validation and experiments would be needed before using them for recommendations.
