# KDD Mining evidence

Generated by `analysis/kdd_mining.py` and `analysis/kdd_interpret.py`.

- `cluster_selection.csv`: silhouette and inertia for k=2 through k=6.
- `cluster_summary.csv`: customer counts and mean RFM values by cluster.
- `customer_clusters.csv`: customer-level cluster assignments.
- `association_rules_top100.csv`: ranked product pairs.
- `association_rules_interpreted.csv`: ranked rules with product descriptions.
- `fig_02_customer_clusters.png`: RFM cluster visualization.
