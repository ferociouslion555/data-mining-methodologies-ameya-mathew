# KDD preprocessing artifacts

Generated by `analysis/kdd_preprocess.py`.

- `preprocessing_audit.csv`: first applicable exclusion reason for every raw row.
- `preprocessing_summary.csv`: row counts and percentages by decision.
- `clean_transactions.csv`: derived positive, identified, non-cancelled transaction table.

The clean CSV is a local derived artifact and can be regenerated from `data/Online_Retail.xlsx`.
